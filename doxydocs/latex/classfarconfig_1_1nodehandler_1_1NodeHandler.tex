\doxysubsection{Detailed Description}
The Node\+Handler class creates a {\itshape node} diagram of the current set of {\itshape modules} by using the \doxylink{classfarconfig_1_1nodehandler_1_1NodeHandler_ad25e3f70d1a406fe7b22bb1823f9e83e}{add\+Dynamic\+Node\+Set} function which is merely a caller for the \doxylink{classfarconfig_1_1dynamicnodes_1_1dynamicNodeSet}{dynamic\+Node\+Set} class. 

Connections in between the various {\itshape nodes} are created by the \doxylink{classfarconfig_1_1nodehandler_1_1NodeHandler_adffa7e44c9f75eaabde4448c4c9adbd0}{parse\+Command} function by parsing {\itshape command} {\itshape responses} received, it also adds the {\itshape glue} {\itshape logic} {\itshape nodes} in between {\itshape nodes} in order to simplify the visual aspects of equations and functions used.~\newline
~\newline
 {\itshape Glue} {\itshape logic} {\itshape nodes} are then optimized \& combined through the use of the \doxylink{classfarconfig_1_1nodehandler_1_1NodeHandler_a717409d6bf031065bc426bb0f9d50286}{post\+Build\+Update} function which also uses the \doxylink{classnodeorganizer_1_1NodeOrganizer}{Node\+Organizer} class to visually organize the {\itshape nodes}.
