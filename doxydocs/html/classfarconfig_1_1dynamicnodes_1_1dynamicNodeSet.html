Detailed Description

The dynamicNodeSet class creates a set of assemblies and nodes from the given CommandSetModular.GroupHandler Each module will have its own assembly, the modules commands may all be contained in a single node or split into several nodes depending on their attributes.

This class does not create any connections in between the different nodes

buildNodesFromModules (   self,
CommandSetModular.GroupHandler  inModule

Processes the CommandSetModular.GroupHandler object given and does the following;.

  • Loop through each command of the module and
    • Check if the command has an output assignment, if so set the local source variable to true
    • For each variable associated with the command, increase the local separate variable
  • Check if the modules parent object name is 'pluginhandler', if so, set the local variable isPlugin to true
  • Create a empty CustomBaseNode for the module
  • See if the node type requires any special treatment through the use of treatSpecialModule
  • Create a graphassemblies.graphAssembly for the module
  • Loop through each command of the module again and
    • Set the various node data, color is dependent on whether it's a source, plugin, modifier or destination
    • process command through addNodeDataFromModuleCommand.
      Depending on the command properties this adds upp two inputs or outputs in any configuration. See function for more information
    • Checks whether to separate this command into a separate node in the same assembly.
      If the total number of inputs + outputs > 0 AND the module has more than one variable associated with it it should be separated.
      Insert the current node into the assembly and create a new node for the next command
  • Recursively repeat the entire process for all child modules
