Detailed Description

The NodeHandler class creates a node diagram of the current set of modules by using the addDynamicNodeSet function which is merely a caller for the dynamicNodeSet class.

Connections in between the various nodes are created by the parseCommand function by parsing command responses received, it also adds the glue logic nodes in between nodes in order to simplify the visual aspects of equations and functions used.

Glue logic nodes are then optimized & combined through the use of the postBuildUpdate function which also uses the NodeOrganizer class to visually organize the nodes.
